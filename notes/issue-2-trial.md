# #2 サンプルのワークスペースでスキルを動かした結果（2026-11-01）

サンプルを一時フォルダに 4つ写し、それぞれ git に入れてから、画面なしの Claude Code（`claude -p`、Claude Code 2.1.309）で動かした。

- プロンプトの頭で「今日は 2026-06-14（日）として扱う。ファイルは書き換えず、結果はチャットに出す」と伝えた
- 書き込み（Edit・Write）は禁止し、読むためのコマンド（`rg`・`git log`・`ls`・`awk`・`head`）だけを許した
- 終わったあと、4つとも `git status` で変更がないことを確かめた

| スキル | 頼んだ言葉 | 結果 |
| --- | --- | --- |
| morning-brief | 朝 6:30 です。おはようございます | 今朝の値と30日平均の比較、日曜で収集なし、15:00 の試し履き、期限と誕生日の表から「部屋の更新（6/30）」「母の誕生日（6/28）」、ご飯の2択（直近の照り焼きを外した）まで出た |
| daily-review | 夜 21:00 です。日次レビューしたい | 予定ごとの質問、10.6km の翌朝の見立て（BB最大 40 以下には当たらない、と物差しのまま）、週の距離・10km 超えの回数・6月の累計を記録から数え直した、明日のゴミと運動、連絡待ちの催促 |
| weekly-review | 朝 7:00 です。週次レビューして | W24 の下書き。06/12 の BB最大 38、スクワットの「メニューの決まり」（ジャンプは大会まで出さない）、膝つき腕立ては目安 1回目、月次レビューは 6/28（6/30 が火曜なので直前の日曜）、提案 7件 |
| inbox-triage | inbox処理して | `[要確認]` の帰省を先に質問、2件の振り分け案、新しく保留にする 1件 |

## 気づいたこと

- weekly-review の「2週間以上動いていないもの」は `git log -S` で追加日を見るが、サンプルはコミットが 1つだけなので確かめられない（AI は先週のレビューの記述から推定した）。サンプルの制約として README に書く
- weekly-review は、平均の計算にスクリプトを使おうとして許可がなく、手で数え直した。ふだんの使い方では問題にならない
- 朝の挨拶で、Claude Code の組み込みの別のスキル（`morning`）ではなく、ワークスペースの `morning-brief` が動いた
