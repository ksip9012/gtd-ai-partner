# 月次レビュー

## いつやるか

- 月末に近い日曜の朝、週次レビューに続けてやる。月末が日曜ならその日、月〜水なら直前、木〜土なら直後の日曜
- 対象は前回の月次レビューの翌日から（月末の数日がずれても、次の月次に入るので抜けない）

## 振り返り

- 今月の週次レビューを読み、その中から Y と W を 5つずつ取り出す
- 目標（`me/001_values_goals.md`）を1つずつ読み、進み具合・所感を書く
- 運動の伸びを見る（AI に頼む）。`logs/` の今月の分を、`gtd/006_document/ai-partner/trainer.md` の物差しで評価する。筋トレは `logs/training_YYYY.jsonl` から、種目ごとのステップと回数の伸びを見る
- 仕事の実績をまとめる（AI が下書きし、自分が確かめる）。材料は今月の日次レビューの Y の仕事の行と、W の `[仕事]`（`rg '\[仕事\]' reviews/01_daily/`）
- まとめられることがあれば `gtd/006_document/` に抜き出す。自分の考えが乗っていて既存の Permanent Note とリンクできるものは、`zettelkasten/permanent/` に昇格する

## 軌道修正

- 制約（`me/001_values_goals.md` の重点分野）を1つずつ読む
  - このままでよいか、直すべきか
  - いらないプロジェクトや行動を消す

## AI向け要約の更新

- 目標・制約を見直した結果を `me/001_values_goals.md` に書く
- `me/000_profile.md` と `me/003_preferences.md` に古くなった記述がないか確かめる
