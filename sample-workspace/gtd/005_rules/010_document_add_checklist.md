# ドキュメント追加時のチェックリスト

`001_inbox.md` の項目を `004_document/` に振り分ける際のルール（Inboxの一次振り分けで「資料・知識」と判断したもの）。

Zettelkastenへの昇格はInbox処理の時点では判定しない。`004_document`や`002_project`を見返すタイミングで別途検討する（`zettelkasten/000_rules.md` 参照）。

## 1. 型を判定する

- [ ] 知識ノート型 (`type: knowledge`): 気になった言葉・知見・考え方など、後から参照する知識
- [ ] 構造化レコード型 (`type: record`): 行ったお店・観た映画など、決まった列を持つデータ。1種類1ファイルの表にまとめ、1件=1行で書く
- [ ] 時系列ログ型 (`type: log`): 出来事の経緯など、日付順に積むもの

## 2. 置き場所を決める

- [ ] 内容に合う分野のフォルダ（`life/` など）に置く。合うものがなければ、分野のフォルダを1つ作る
- [ ] AI パートナーの決めごと（物差し・チェックリスト）は `ai-partner/` に置く

## 3. 既存ファイルへの追記か、新規作成か

- [ ] 近いトピックのファイルがあれば追記する
  - `type: knowledge` → `## メモ` 配下に新しい `###` 見出しを追加
  - `type: log` → 末尾に新しい日付見出しを追加
  - `type: record` → 表に1行足す
- [ ] なければ新規作成する（同じフォルダの既存ファイルの frontmatter を踏襲する）

## 4. frontmatter を確認する

- [ ] `type` フィールドが3種類のいずれかで設定されているか
- [ ] `tags` は配列形式になっているか
- [ ] 追記した場合、`updated` を更新したか
