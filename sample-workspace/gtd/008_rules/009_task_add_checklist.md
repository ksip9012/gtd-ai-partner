# タスク追加時のチェックリスト

## 1. これはNext Actionか？

- [ ] 物理的で具体的な行動か？
- [ ] 動詞で始まっているか？
- [ ] 2分以内に着手できる粒度か？
- [ ] 誰かに依頼する必要はないか？（もしそうなら`004_waiting_for.md`へ）

## 2. プロジェクトに属するか？

- [ ] もしプロジェクトに属するなら、頭に `プロジェクト名:` を書き、詳細はプロジェクトのファイルに書いてリンクしているか？ `todo` にはそのプロジェクトの Next Action のみを置く

## 3. いつ・どこでならできるか

- [ ] 本文から読み取りにくいなら、`@外出` `@スマホ` `@週末` のどれかを付けているか？（付けるのは必要なときだけ）

## 4. 日付は適切か？

- [ ] 特定の日付に実行すべきタスクか？そうであれば「カレンダー」に日付付きで書いているか？
