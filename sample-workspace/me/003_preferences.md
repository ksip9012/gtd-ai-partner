# 好み・判断基準・AIへの頼み方

## AIとのやり取り

- 選択肢を並べるだけでなく、推奨を示してほしい
- 推定で書いた内容は推定だと明示する
- 朝は短く。1分で読める量にしてほしい

## 道具・技術の選び方

- メモは Markdown と git にまとめる。特定のアプリの同期機能には頼らない
- 新しい技術は、小さく作って試してから決める

## 人付き合い

- 大人数より、少人数でゆっくり話すほうが好き

## 書き方のルール

- Markdownの箇条書きはスペース2個でインデントする

## プライバシー

- 第三者の連絡先は、ワークスペースに書かない（スマホの連絡先だけで管理する）
- 仕事の内容は、会社名・案件名・人名を外して書く
