# 価値観・目標

AI がメンターとして振り返りや取捨選択を手伝うときの判断基準。月次・年次レビューで見直す。

## 価値観

- 健康でいること。体が整っていれば、ほかのこともうまく回る
- 作ったもので人の役に立つこと
- 無理をしない。続けられる形を選ぶ

## 理想

- 5年後: フロントエンドとバックエンドの両方がわかるエンジニアになり、小さなプロダクトを1人で作って出せる
- 走ることが生活の一部になっていて、毎年ハーフマラソンに出ている

## 目標

- 2026-10: ハーフマラソンを完走する（目標 2時間10分以内）
- 2026-12: Go でバックエンドの小さな API を作り、個人のサイトに載せる
- 2026 年中: リーダーとして、後輩 2人と月1回は 1on1 をする

## 制約（重点分野）

| 分野 | 最低ライン |
| --- | --- |
| 仕事 | 残業は週5時間まで |
| 健康 | 睡眠 7時間。運動は週3回 |
| お金 | 毎月、決めた額を積み立てる |
| 生活 | ゴミの日を逃さない。週末に作り置きをする |
| 人間関係 | 月に1回は友人と会う |
