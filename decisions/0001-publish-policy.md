# 0001. 公開方針は「GitHub 公開まで」とし、作り物のサンプルデータだけを公開する

- Status: Accepted
- Date: 2026-11-01

## Context

プロジェクト開始時に、公開方針（誰に見せるか・継続利用するか・運用コスト・公開可否）を決めておく必要があった。

- 見せたい相手: 転職活動でアピールしたい。AI エージェントを日常に組み込む仕組みの例として見せる
- 継続利用: 作者自身が毎日使い続ける。改善も続ける
- 運用コスト: なし（ローカルの AI エージェントと Markdown だけで動く）
- 公開可否: 元になった作者の Vault には、お金・キャリア・健康の記録や人の名前が入っている。仕組み（スキル・ルール・フォルダの形）は公開できるが、Vault の中身は公開できない

## Decision

公開方針は「GitHub 公開まで」とする。常時稼働のデモは用意しない。

公開するのは、スキル・ルール・フォルダの形と、作り物のサンプル Vault だけにする。リポジトリは Private で作り、個人の情報（アカウント名・カレンダーの ID・Vault のパスなど）を抜き終わってから Public に切り替える。

## Consequences

- 読んだ人が試せるように、サンプル Vault を作る手間がかかる
- 作者の Vault から写すたびに、個人の情報が混ざっていないかを確かめる必要がある
- デモの運用コストはかからない
