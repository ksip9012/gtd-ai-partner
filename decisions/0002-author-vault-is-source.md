# 0002. 最初は作者の Vault のスキルを正にし、このリポジトリには汎用に直したものを写す

- Status: Accepted
- Date: 2026-11-01

## Context

スキルは作者の Vault の中で毎日使いながら直している（2026-10-31〜11-01 の 2日でも、レビューの時期や朝のニュースの扱いが変わった）。公開用のリポジトリと Vault のどちらを正にするかを決める必要があった。

- このリポジトリを正にして Vault から読み込む形にすると、Vault 固有のパスや決めごとを設定ファイルに出し切る必要があり、v0.1 の公開に間に合わない
- Vault を正にすると、写す手間と、2つの中身がずれる心配がある

## Decision

最初は作者の Vault のスキルを正にする。このリポジトリには、個人の情報を抜いて汎用に直したものを写す。

## Consequences

- v0.1 を早く公開できる
- Vault でスキルを直したら、こちらにも写す手間がかかる。ずれが増えてきたら、このリポジトリを正にする形（0002 を Superseded にする）を考える
